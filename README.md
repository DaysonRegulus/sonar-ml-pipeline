# 🔊 Sonar Signal Classifier
This project uses a logistic regression model to classify sonar signals as either rocks or mines.
## 📌 Dataset
- 208 samples, 60 features representing sonar signals bounced off surfaces.
- Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/connectionist+bench+(sonar,+mines+vs.+rocks))
## ⚙️ Technologies
- Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn
## 🚀 Usage
```bash
pip install -r requirements.txt
jupyter notebook SonarProject.ipynb
```
## 🗃️ File Structure
- `SonarProject.ipynb`: Main notebook
- `data/`: Dataset
- `models/`: Trained model
- `images/`: Visual outputs
